Ninguna imagen de `material-diseno/` quedó sin identificar. Estos recursos faltan y hoy se sustituyen por
alternativas honestas en SVG/CSS (no se declara fidelidad visual final con ellas):

| Recurso | Uso | Formato y tamaño sugeridos |
|---|---|---|
| Barquito de vela | Recuerdo «barquito» en la mesa del rincón | PNG con alfa real, ~1024 px de alto, sin sombra pintada |
| Planta en maceta | Recuerdo «planta» | PNG con alfa, ~1024 px |
| Tintero con pluma | Recuerdo «tintero» | PNG con alfa, ~1024 px |
| Mapa enrollado | Recuerdo «mapa» | PNG con alfa, ~1024 px de ancho |
| Ramas de adorno (5 variantes: cerezo, dark academia, constelaciones, jardín de cartas, bosque de tinta) | `ReaderAdornment` bajo el avatar | PNG con alfa, 1024×512, arco inferior que rodee un círculo de 512 px |
| Distinciones (cinta con estrella, libro y luna, farol salvia, llave con cinta ciruela, casa con plumín, carta sellada) | Insignias de distinción | SVG o PNG con alfa, 256×256 |
